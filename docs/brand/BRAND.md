# Kulisa brand

Minimal, modern, quietly powerful. The engine has no look, so the brand stays out of the way.

## Mark

`logo.svg` is a **K** built from three stage flats: a solid stem, a lit front flat and a
translucent back flat. The layering is a nod to scenery wings and to parallax depth.
`logo-mono.svg` uses `currentColor` for single-color contexts.

Keep clear space of at least one stem width around the mark. Do not add gradients,
outlines, shadows or rotate it.

## Banner

`banner-dark.svg` and `banner-light.svg` (1280×400, text as outlines) head the README, which
picks one by color scheme. The mark stands on a lit stage floor with two copies behind it as
flats further upstage. `social-preview.png` (1280×640) is the repository's social preview
image (GitHub: Settings → General → Social preview).

## Color

| Token     | Hex       | Use                                   |
|-----------|-----------|---------------------------------------|
| Ink       | `#111116` | Backgrounds, primary text on light    |
| Paper     | `#F4F1EA` | Primary text on dark, light surfaces  |
| Footlight | `#FF6A3D` | The one accent: links, focus, the arm |
| Haze      | `#8A8794` | Secondary text, rules, disabled       |

One accent only. Everything else is Ink, Paper and Haze.

## Type

- UI and docs: Inter (fallback: system sans).
- Code: JetBrains Mono (fallback: system mono).
- The wordmark is `Kulisa` (capital K), Inter SemiBold, tracking -2%.
- Prose, titles and UI always write Kulisa. Code identifiers (crates, CLI,
  `.kulisa` files, the `kulisa` Luau global) stay lowercase by convention.

## Voice

Short, plain, confident. Say what it does, not how amazing it is.
