# Art sources for demos/pc-unwrap

The demo's case, room, foil, tape and squeegee are WGSL; the unboxing scene (the cardboard box, the
foam blocks, the case in the box) is rendered from 3D models made in Blockbench. Everything here
is original and generated by scripts, so the assets can be rebuilt.

| File | What |
|---|---|
| `textures/make_textures.py` | Writes the model textures (cardboard, printed front, foam beads, case) as PNGs. No dependencies. |
| `build_models.py` | Writes the `.bbmodel` files: the box with its flaps animation (`open`), the front wall, the foam blocks, the case, as separate layers with identical framing. |
| `pngtools.py` | Post-processes the renders: clears the ground shadow, crops all layers to one common rectangle, scales them down. |
| `gen_audio.py` | Synthesizes the demo's sounds into `demos/pc-unwrap/audio`. |

Rebuilding the box renders:

1. `python textures/make_textures.py`, then `python build_models.py <a folder>` (copy the textures there too).
2. Render each model with Blockbench's renderer (the `bb-render` CLI or the Blockbench MCP's render
   tool): view `front`, preset `showcase`, `studio` lighting, transparent, 1600x1200. `unbox_all` at
   the times 0, 0.12, 0.25, 0.4, 0.55, 0.7, 0.85 (clip `open`) give `frame0..6`; the others at time 1
   give `back_empty`, `case`, `foam_left`, `foam_right`, `front` (and `back_nofoam`). Name the files
   `<name>_lit.png` in one folder.
3. `python pngtools.py <that folder> demos/pc-unwrap/images/unbox 0.8`.
